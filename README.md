# 🛒 Retail — Android Shopping App

An Android application for browsing and managing retail product listings. Built as an early exploration of Android development with Java.

## 📱 Features

- Browse product catalogue
- View product details
- Basic cart / retail flow UI

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Language | Java |
| Platform | Android |
| Build System | Gradle |
| IDE | Android Studio |

## 🚀 Getting Started

### Prerequisites
- Android Studio (any recent version)
- Android SDK (API 21+)
- Java 8+

### Run Locally

```bash
# Clone the repository
git clone https://github.com/aishwary08/Retail.git

# Open in Android Studio
# File → Open → select the cloned folder

# Build and run on an emulator or physical device
```
